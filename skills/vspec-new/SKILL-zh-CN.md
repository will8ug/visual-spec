# VSpec New Skill（中文）

将简短的业务请求转化为结构化的需求输出，在 `/specs/` 下生成基线规格产物。

## 何时使用

- 业务方提供了非常简单描述的需求。
- 用户运行 `/vspec:new` 开始新的需求分析流程。

## 本 Skill 的作用范围

- 基于场景驱动法补齐细节。
- 输出结构化需求文档（markdown 规格、流程图和功能清单——不可运行代码）。
- 本 Skill 不生成原型、数据模型、测试用例或实现代码。

## 范围边界

本 Skill 止于需求分析输出。完成后，使用其他 Skill 进行后续阶段：
- `vspec-detail` → 每功能详细规格
- `vspec-verify` → 数据模型与可运行原型
- `vspec-impl` → 前后端代码生成

不要在本 Skill 内超出需求分析范围——后续阶段由独立 Skill 处理。

> 完整的命令流程请参见 `SKILL.md`（英文版）。
