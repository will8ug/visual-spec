# vspec append test Skill（日本語）

この Skill は既存プロジェクト向けのテストコードを生成します。JSON テストケース定義は vspec-accept または vspec-i-test を使用してください。

> 完全なコマンドフローについては `SKILL.md`（英語版）を参照してください。
